# Tempo — Clock & Timer

Tempo is a responsive clock and timer app that runs in your browser. It is built with plain HTML, CSS, and JavaScript; no installation or build step is required.

## Run

Open `index.html` in a modern web browser.

## Features

- Live digital and analog clock
- Switch between 12-hour and 24-hour time
- Choose your device's local time or a city in another time zone
- Countdown timer with preset durations, pause/resume, reset, and an audio alert
- Stopwatch with pause/resume, reset, and lap times
- Dark and light themes
- Fullscreen mode
- Saves your theme, time format, and selected time zone in browser storage

## Browser support

Use a modern browser with support for the JavaScript Internationalization API. Fullscreen and timer audio depend on browser support and permissions; timer audio starts after you interact with the page.
